## FAQ

**Welche Technik wird verwendet?**
Node.js mit Express im Backend, eine schlanke Oberfläche ohne Framework (HTML, CSS, JavaScript) und optional Docker.

**Sind die Monitoring-Daten echt?**
Die Demo nutzt simulierte Werte. Die Anbindung an echte Systeme (z. B. Prometheus, Datadog oder eine eigene API) ist als Extra auf Anfrage möglich.

**Kann ich eine Datenbank wie PostgreSQL nutzen?**
Standardmäßig werden die Daten in einer JSON-Datei gespeichert. PostgreSQL oder MySQL und Redis für mehrere Server gibt es als Extra auf Anfrage.

**Was zählt als Revision?**
Eine Revision ist eine gesammelte Liste von Änderungswünschen am gelieferten Stand (Texte, Farben, Anordnung, kleine Funktionsanpassungen). Neue Seiten oder neue Funktionen zählen nicht als Revision.

**Bekomme ich den Quellcode?**
Ja, in allen Paketen – komplett und ohne Lizenzgebühren.

**Hilfst du bei der Installation?**
Jedes Paket enthält eine Schritt-für-Schritt-Anleitung. Im Premium-Paket bekommst du zusätzlich ein Anleitungsvideo, das Installation und alle 8 Seiten zeigt.
