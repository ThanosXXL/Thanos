## FAQ

**Do I have to pay monthly license fees?**
No. You get the full source code and run the app on your own server – no subscription costs.

**Does it work on mobile phones?**
Yes. The interface is fully responsive and can be installed like an app on Android and iOS.

**Which languages does the interface support?**
The interface is German by default. An English (or any other) interface can be added with the "Additional interface language" extra.

**Can you add custom fields or modules?**
Yes. The platform is modular, so new fields and sections are added to match your exact workflow.

**Where is the app hosted?**
On your own server or VPS (e.g. with Docker). From the Standard package on, I set up hosting with HTTPS for you.

**Is my data secure?**
Passwords are securely hashed, there are roles and permissions, and every tenant has a fully isolated data area.

**Can I run it as my own SaaS business?**
Yes. The platform is multi-tenant: several companies can sign up and each works in its own isolated workspace.
