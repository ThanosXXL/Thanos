# IT-World — Markenmaterial

Dies ist das dauerhafte, firmenweite Markenmaterial von **IT-World** (IT
Solutions) — dem Unternehmen hinter den Softwareprojekten in diesem
Repository, nicht eines der Produkte selbst. Es ist absichtlich getrennt von
`pharma-tech-prototype/` und den anderen Projektordnern, damit es
projektübergreifend wiederverwendet werden kann.

## Inhalt

- **`logo.png`** (2400×2400) — das offizielle IT-World-Logo: schwarzer
  Hintergrund, goldener 3D-Glanz-Globus mit Ring, Schriftzug "IT-WORLD" in
  Gold, Slogan **"IT Solutions"** in Weiß darunter.

## Verwendung

Für jedes neue oder bestehende Projekt in diesem Repository, das einen
Firmenbezug zu IT-World braucht (Impressum, Vertragsdokumente, Kontaktseiten,
Lizenzdialoge, E-Mail-Signaturen o. Ä.), dieses Logo von hier referenzieren
bzw. kopieren — nicht neu erfinden oder durch ein Platzhalter-Icon (z. B. das
Pharma-Tech-Tropfen-Icon) ersetzen. Das Pharma-Tech-Tropfen-Logo ist die
Produktmarke von Pharma-Tech und unabhängig von diesem Firmenlogo.
