# Kundenverwaltung DELUXE — Branding-Assets

Demo-Material für das CRM-Feature (`Kundenverwaltung DELUXE`), dauerhaft im
Repository gesichert statt nur in einer Chat-Session zu existieren.

- **crm-kundenverwaltung-demo.mp4** – ~26s Video-Walkthrough des CRM
  (Kunde anlegen, Status-Pipeline, Notizen-Verlauf, Suche), mit
  Begleitmusik unterlegt, dunkelbraun/gold Hochglanz-Look. Zeigt
  ausschließlich die CRM-Oberfläche — kein Dozenten-Bezug (siehe
  CLAUDE.md-Regel zur strikten Trennung beider Features).
- **kundenverwaltung-deluxe-player.html** – interaktive, eigenständige
  Quelldatei mit eingebettetem Video-Player und Download-Button. Einfach
  im Browser öffnen.
- **crm-theme-music.wav** – die Begleitmusik einzeln: Klavier (Melodie +
  Bass-Begleitung), Streicher-Pad und ein weicher Kick/Rim-Beat, ~26s,
  exakt auf die Videolänge zugeschnitten.

Das Video ist aus Playwright-Screenshots der App plus ffmpeg-Crossfades
zusammengesetzt. Die Musik ist eine eigene Komposition (selbst geschriebene
MIDI-Melodie), gerendert mit Fluidsynth und dem freien, MIT-lizenzierten
FluidR3-GM-Soundfont (Klavier/Streicher/Percussion-Instrumente) — keine
Aufnahme oder Nachbildung eines bestehenden Songs, lizenzfrei nutzbar für
dieses Projekt.
