# Branding-Assets (separat, nicht Teil des Dozenten Dashboards)

Dieser Ordner enthält fertige Demo-/Musik-Assets für ein **anderes, eigenständiges
Projekt** ("MSR_DELUXE"-Anlagendashboard) und wurde unverändert aus dem Branch
`claude/msr175-dashboard-demo-fyhsly` übernommen, damit die Dateien dauerhaft
gesichert sind. Sie stehen in keinerlei Bezug zum Dozenten Dashboard
(`main.js`, `preload.js`, `renderer/`) und werden von dessen Build/Installer
nicht mitverpackt.

- **msr-deluxe-dashboard-demo-with-music.mp4** – Demo-Video mit eingebetteter
  Hintergrundmusik.
- **msr-deluxe-video-player.html** – eigenständige Seite mit Video-Player
  (Poster-Frame + Download-Button). Einfach im Browser öffnen.
- **lounge-band.mp3** – die Hintergrundmusik einzeln (~30s).
- **lounge-session-player.html** – eigenständige Seite mit Musik-Player
  (Play/Pause, Visualisierung + Download-Button). Einfach im Browser öffnen.

Laut Angabe im Ursprungs-Branch sind die Assets synthetisch/prozedural erzeugt
(ffmpeg-Audiosynthese, Fluidsynth + General-MIDI-Soundfont,
Playwright-Aufnahmen von HTML-Vorlagen) und lizenzfrei nutzbar.
