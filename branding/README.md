# M&C Akademie Branding

`mc-akademie-logo.svg` is a glossy 3D vector recreation of the M&C Akademie logo
(red swoosh + black ring + arrow-styled "A", light plaque backdrop), built for reuse
in documents and materials that need the brand mark on either a light or dark page.

It's a stylized recreation of a reference image provided in chat, not a byte-identical
trace of an original vector source. `viewBox="0 0 560 220"` — scale freely, aspect
ratio 28:11.
