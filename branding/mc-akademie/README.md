# M&C Akademie – Logo-Assets

Nicht Teil der Dozenten-Dashboard-App oder von `omniroute/`. Abgelegt hier, damit das Logo
sitzungsübergreifend wiederverwendbar ist (z.B. für Anschreiben/Konzeptdokumente der M&C Akademie).

- `logo-original.png` – Originallogo (weißer Hintergrund, wie vom Nutzer bereitgestellt)
- `logo-glossy-3d.png` – bearbeitete Hochglanz-/3D-Version (transparenter Hintergrund, Schlagschatten,
  Glanzstreifen, Kantenrelief), erzeugt aus dem Original via `PIL`/Python. Skript zur Reproduktion
  war `make_glossy_logo.py` (Scratchpad, nicht Teil dieses Repos).
