# Vendored project

This directory is a vendored copy of [OmniRoute](https://github.com/diegosouzapw/OmniRoute),
an open-source AI gateway, included here as a standalone project alongside the
Dozenten Dashboard app at the repository root.

- Source: https://github.com/diegosouzapw/OmniRoute
- Vendored at commit: `ee4cd0d795c89162ee403679232e075959aaddcb`
- License: MIT (see `LICENSE` in this directory)

This is a snapshot, not a live sync — pulling upstream updates requires manually
re-vendoring (or switching to a submodule) rather than `git pull`.
