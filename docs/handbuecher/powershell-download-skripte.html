WIN

1 · Windows .exe

Laedt den neuesten Windows-Installer (NSIS-Setup) aus dem GitHub-Release herunter.

$repo = "ThanosXXL/Thanos"
$release = Invoke-RestMethod -Uri "https://api.github.com/repos/$repo/releases/latest"
$asset = $release.assets | Where-Object { $_.name -like "*.exe" } | Select-Object -First 1
Invoke-WebRequest -Uri $asset.browser_download_url -OutFile $asset.name
Write-Host "Heruntergeladen: $($asset.name)"
PowerShell
PS C:\Downloads> .\download-windows.ps1 Heruntergeladen: Dozenten Dashboard Setup 1.0.0.exe
Beispiel: erwartete Ausgabe nach dem Ausfuehren
Anschliessend die heruntergeladene .exe-Datei per Doppelklick ausfuehren.

AND

3 · Android .apk

Laedt das selbstsignierte Debug-APK herunter (Sideload, kein Play Store noetig).

$repo = "ThanosXXL/Thanos"
$release = Invoke-RestMethod -Uri "https://api.github.com/repos/$repo/releases/latest"
$asset = $release.assets | Where-Object { $_.name -like "*android*.apk" } | Select-Object -First 1
Invoke-WebRequest -Uri $asset.browser_download_url -OutFile $asset.name
Write-Host "Heruntergeladen: $($asset.name) - danach aufs Android-Geraet uebertragen und antippen."
PowerShell
PS C:\Downloads> .\download-android.ps1 Heruntergeladen: dozenten-dashboard-android.apk - danach aufs Android-Geraet uebertragen und antippen.
Beispiel: erwartete Ausgabe nach dem Ausfuehren
Auf dem Geraet einmalig "Installation aus unbekannter Quelle zulassen" bestaetigen.
iOS

4 · iOS PWA

Ohne kostenpflichtiges Apple-Developer-Konto ist keine installierbare .ipa moeglich - stattdessen der Web-App-Weg.

Write-Host "Fuer iOS gibt es keine herunterladbare .ipa-Datei (erfordert kostenpflichtiges Apple-Developer-Konto)."
Write-Host "Stattdessen: docs/demo.html bzw. renderer/index.html per GitHub Pages veroeffentlichen,"
Write-Host "dann auf dem iPhone/iPad in Safari oeffnen -> Teilen -> 'Zum Home-Bildschirm' antippen."
PowerShell
PS C:\Downloads> .\ios-hinweis.ps1 Fuer iOS gibt es keine herunterladbare .ipa-Datei (erfordert kostenpflichtiges Apple-Developer-Konto). Stattdessen: docs/demo.html bzw. renderer/index.html per GitHub Pages veroeffentlichen, dann auf dem iPhone/iPad in Safari oeffnen -> Teilen -> 'Zum Home-Bildschirm' antippen.
Beispiel: erwartete Ausgabe nach dem Ausfuehren
Die App startet danach im Vollbild vom Home-Bildschirm aus, wie eine echte App.
Voraussetzung: Der Versions-Tag (z. B. v1.0.0) muss bereits gepusht und der GitHub-Actions-Workflow "Build & Release Desktop App" durchgelaufen sein, damit ein Release mit diesen Dateien existiert.
