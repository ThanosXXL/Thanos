WIN

1 · Windows .exe

Installer herunterladen und ausfuehren - kein Terminal noetig.

  1. Download-Seite oeffnen (siehe Link unten) und auf "Download" bei Windows klicken.
  2. Die heruntergeladene Datei BaustelleTagesreport-Windows-Setup.exe per Doppelklick ausfuehren.
  3. Falls "Windows hat den PC geschuetzt" erscheint: auf "Weitere Informationen" → "Trotzdem ausfuehren" klicken (normal bei Installern ohne teures Code-Signing-Zertifikat).
  4. Dem Installationsassistenten folgen - fertig.
MAC

2 · macOS .dmg

Disk-Image herunterladen und die App in den Programme-Ordner ziehen.

  1. Download-Seite oeffnen und auf "Download" bei macOS klicken.
  2. BaustelleTagesreport-macOS.dmg oeffnen.
  3. Das App-Symbol in den angezeigten "Programme"-Ordner ziehen.
  4. Beim ersten Start ggf. per Rechtsklick → "Oeffnen" bestaetigen (da die App nicht im Mac App Store signiert ist).
LNX

3 · Linux .AppImage

Keine Installation noetig - einmal ausfuehrbar machen, dann direkt starten.

  1. Download-Seite oeffnen und auf "Download" bei Linux klicken.
  2. BaustelleTagesreport-Linux.AppImage ausfuehrbar machen: Rechtsklick → Eigenschaften → "Ausfuehrung erlauben", oder im Terminal chmod +x BaustelleTagesreport-Linux.AppImage.
  3. Datei per Doppelklick starten.
AND

4 · Android .apk

Selbstsigniertes APK, Installation ausserhalb des Play Stores (Sideload).

  1. Download-Seite auf dem Android-Geraet oeffnen und auf "Download" bei Android tippen.
  2. BaustelleTagesreport-Android.apk antippen, um die Installation zu starten.
  3. Bei der Meldung "Installation aus unbekannter Quelle zulassen" einmalig bestaetigen (das ist normal fuer Apps ausserhalb des Play Stores).
  4. App oeffnen - fertig.
iOS

5 · iOS PWA

Ohne kostenpflichtiges Apple-Developer-Konto ist keine installierbare .ipa moeglich - stattdessen der Web-App-Weg.

  1. Download-Seite in Safari oeffnen (nicht Chrome - "Zum Home-Bildschirm" funktioniert nur in Safari) und bei iOS auf "Web-App oeffnen" tippen.
  2. Unten auf das Teilen-Symbol (Quadrat mit Pfeil nach oben) tippen.
  3. "Zum Home-Bildschirm" auswaehlen.
  4. Die App erscheint danach als eigenes Icon auf dem Home-Bildschirm und startet im Vollbild, ganz ohne Browser-Leiste.

6 · Anhang: PowerShell-Download optional

Alternative zum Download-Button für Nutzer, die lieber per Skript installieren. Jedes Snippet laedt die Datei direkt herunter - kein Login, keine Zwischenabfrage noetig.

Windows .exe

$url = "https://github.com/ThanosXXL/Thanos/releases/download/tagesreport-v1.0.1/BaustelleTagesreport-Windows-Setup.exe"
Invoke-WebRequest -Uri $url -OutFile "BaustelleTagesreport-Setup.exe"
Start-Process "BaustelleTagesreport-Setup.exe"

macOS .dmg

$url = "https://github.com/ThanosXXL/Thanos/releases/download/tagesreport-v1.0.1/BaustelleTagesreport-macOS.dmg"
Invoke-WebRequest -Uri $url -OutFile "BaustelleTagesreport.dmg"
open "BaustelleTagesreport.dmg"

Laeuft mit PowerShell (pwsh), das auch auf macOS installierbar ist; open ist der macOS-Befehl zum Oeffnen der Datei.

Android .apk

$url = "https://github.com/ThanosXXL/Thanos/releases/download/tagesreport-v1.0.1/BaustelleTagesreport-Android.apk"
Invoke-WebRequest -Uri $url -OutFile "BaustelleTagesreport.apk"

Datei anschliessend per USB/Cloud aufs Android-Geraet uebertragen und antippen.
