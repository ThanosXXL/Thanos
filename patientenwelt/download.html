Wichtig vor der Installation

Unsignierte Installer: Die Windows-/Mac-Installer sind nicht mit einem kostenpflichtigen Herausgeber-Zertifikat signiert (reines Demo-Projekt). Windows SmartScreen zeigt daher „Unbekannter Herausgeber" — über „Weitere Informationen → Trotzdem ausführen" fortfahren. macOS Gatekeeper zeigt „nicht verifizierter Entwickler" — im Finder Rechtsklick auf die App → „Öffnen" wählen, um das einmalig zu bestätigen.

Automatischer Build: Jeder Download wird von GitHub Actions direkt aus dem Quellcode dieses Repositories gebaut (electron-builder, NSIS/DMG/AppImage) und als GitHub-Release veröffentlicht — die Links oben zeigen immer auf den neuesten Stand.

Keine echten Patientendaten verwenden: PatientenWelt ist kein zulassungsfähiges Praxisverwaltungssystem (keine KBV-Zulassung, keine TI-Anbindung). Details siehe README im Repository, Abschnitt „Grenzen".
