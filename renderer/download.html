App herunterladen – für Teilnehmer, Dozenten und Admins, noch bevor du dich zum Unterricht anmeldest.

1-Klick-Download nach Plattform

Deine Plattform wird automatisch erkannt und hervorgehoben. Für Windows/Mac/Linux lädt der Button das Start-Skript der Vollversion herunter (Node.js muss einmalig installiert sein); für Android/iOS lädt er die Vollversion-Broschüre als PDF, da die App dort nicht nativ läuft.

Hinweis: Diese Seite funktioniert auf jedem Rechner, auf dem sie lokal ausgeliefert wird (pwsh ./scripts/start-browser.ps1 bzw. npm run serve → http://localhost:4173/download.html). Für Teilnehmer, Dozenten und Admins über das Internet muss diese Seite zusätzlich öffentlich gehostet werden (z. B. über die PWA auf GitHub Pages, sobald aktiviert). Aus Sicherheitsgründen können Browser eine heruntergeladene Datei nicht automatisch auf dem Desktop speichern – sie landet im üblichen Download-Ordner und kann von dort auf den Desktop verschoben werden.
