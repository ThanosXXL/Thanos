# SteuerWelt-Branding-Assets

Marketing-/Demo-Assets für SteuerWelt, dauerhaft im Repository gesichert
statt nur in einer Chat-Session zu existieren. Wird **nicht** in die
Installer gepackt (nicht Teil der `files`-Liste in `package.json`) —
rein für Demo-Videos und Präsentationen.

- **lounge-band.mp3** — Hintergrundmusik (Klavier & Streicher, ~30 s),
  synthetisch per Fluidsynth + General-MIDI-Soundfont erzeugt, keine
  kommerzielle Fremdmusik, lizenzfrei nutzbar. Ursprünglich für ein
  anderes Demo-Video erzeugt (`branding/lounge-band.mp3` im Branch
  `claude/msr175-dashboard-demo-fyhsly`) und hier für SteuerWelt-Demos
  dauerhaft übernommen.
