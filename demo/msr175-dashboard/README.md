# MSR175 Dashboard – Demo

Eigenständige, statische Demoversion eines überarbeiteten Mess-Dashboards im
Stil eines MSR175-Datenloggers – neu gestaltet in Navy-Blau/Weiß mit
hochglänzendem 3D-Karten-Look, klarer strukturiert als das Original
(Seitenleisten-Navigation, KPI-Kacheln mit Sparklines, Live-Chart,
Ereignisliste).

Diese Demo ist unabhängig von der Dozenten-Dashboard-Electron-App im
Repository-Root und verändert diese nicht.

## Anzeigen

Einfach `index.html` im Browser öffnen (kein Build-Schritt, keine
Abhängigkeiten). Die Messwerte, Sparklines und der Chart werden mit
simulierten Demodaten live aktualisiert.
